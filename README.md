# pc_creation
PC CREATION – Building Smart Digital Solutions

## Overview

**PC CREATION** is a modern and responsive digital agency portfolio website built using **HTML, CSS, and JavaScript**. The website showcases professional web development services, completed projects, company information, and contact details in a clean and interactive design.

It is designed to help businesses, startups, and individuals establish a strong online presence through high-quality, responsive, and user-friendly websites.

### Features

- Modern and Responsive Design
- Interactive User Interface
- Hero Section with Animations
- About Company Section
- Professional Services Section
- Featured Projects with Live Website Links
- Contact Form with WhatsApp Integration
- Smooth Scrolling and Animations
- Mobile-Friendly Layout
- Clean and Well-Structured Code

### Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts
